[更新履歴](/changelog)を、各エントリの本文を全文展開するタイムラインから、日付・カテゴリ・タイトルだけを並べた一覧に変更しました。読みたい回のタイトルから個別ページに移動できます。

このサイトは通読する読み物ではなく必要なときに引くリファレンスなので、更新履歴も「何がいつ変わったか」を一覧で見渡せる形のほうが合っている、という判断です。

あわせて、ヘッダーの「更新履歴」タブが最新エントリの個別ページに飛んでしまっていた挙動を直し、一覧ページに移動するようにしました。[RSS](/changelog/rss.xml) の内容はこれまでどおりです。
